# Changelog

## [0.1.0] - 2026-10-04

### Added
- Unlock rules setting in the Mods menu with four modes: Remastered, Classic, Flexible and Free.
- Classic mode brings back tiered unlocks based on points spent in each tree, using the skill's row in the new grid.
- Flexible mode accepts either a prerequisite or enough tree points.
- Skill tooltips in Classic and Flexible show how many tree points a locked skill still needs.
- Option to keep the Clearing Potion after using it, off by default.
- English and German menu texts.
